PARADIGMAS DE APRENDIZAJE

Machine Learning

El núcleo del aprendizaje computacional: desde modelos predictivos con etiquetas hasta agentes autónomos guiados por recompensas.

TIPO 01 // SUPERVISADO 🎯

Aprendizaje Supervisado

El modelo aprende de datos etiquetados (entradas $X$ con respuestas reales $Y$) mapeando funciones predictivas con error mínimo.

CASOS DE USO PRINCIPALES:
  • • Regresión: Predicción continua (precios, demanda energética, temperatura).
  • • Clasificación: Detección binaria o multiclase (spam, diagnóstico médico).
  • • Predicción: Series temporales y proyección de tendencias financieras.
TIPO 02 // NO SUPERVISADO 🔍

Aprendizaje No Supervisado

Descubre estructuras latentes, grupos naturales y relaciones ocultas en conjuntos de datos no etiquetados ni clasificados previamente.

CASOS DE USO PRINCIPALES:
  • • Clustering (K-Means/DBSCAN): Segmentación de clientes y perfiles.
  • • Reducción de Dimensionalidad (PCA/t-SNE): Compresión y visualización 2D/3D.
  • • Detección de Patrones: Detección de anomalías en redes y transacciones.
TIPO 03 // REFUERZO (RL) 🕹️

Aprendizaje por Refuerzo

Un agente interactúa con un entorno mediante ensayo y error, optimizando una política para maximizar una recompensa acumulada.

Agente → Acción → Entorno → Recompensa
• Aplicaciones: Robótica autónoma, control térmico, AlphaGo, navegación en simulación.

ANÁLISIS ESTADÍSTICO EXPLORATORIO

Simulador de Distribución de Probabilidad Normal

$f(x) = \frac{1}{\sigma \sqrt{2\pi}} e^{-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2}$
Media poblacional (μ): 0.0
Desviación estándar (σ): 1.2
Regla Empírica: El 68.2% de los datos cae a $\pm 1\sigma$, el 95.4% a $\pm 2\sigma$ y el 99.7% a $\pm 3\sigma$. Fundamental para detección de anomalías y contraste de hipótesis.
